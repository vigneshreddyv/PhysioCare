## Connected test sequence and pass criteria

| Gate | Action on fictional data | Required evidence / stop condition |
|---|---|---|
| Identity | Compare deployment marker, DB URL/name/host, credentials' **presence**, TLS origin, proxy, roots, payment-disabled state against approved inventory; verify zero normal records | Stop before seeding on any mismatch, credential leak or normal data |
| Mongo initialization | With explicit DB approval, initialize models and inspect unique/TTL indexes, including `auth_rate_limit_buckets`; verify backup and restoration to a second isolated target | Expected definitions, no unexpected migration or normal DB contact |
| Auth concurrency | From two workers, race first bucket upserts and login/registration/refresh limits; rotate and replay one fictional refresh token; revoke/logout | Shared threshold, at most one refresh winner, replay/session revocation, safe 429/503; no raw identifiers in buckets |
| Proxy | Send forged forwarding headers through the real ingress and directly from an untrusted peer | Ingress overwrites; spoofing cannot alter throttle identity; Secure cookies and CSRF behave behind HTTPS |
| Booking/report | Run the guarded connected transaction contract, race appointment slot claims, submit patient A with patient B's lab booking, and separately kill a worker before/after transaction commit | One slot/booking winner, no cross-patient mutation, and no committed booking without its report or report without its completed booking; unsupported transactions fail closed |
| Storage/scanner | Run approved clean, EICAR, malformed, polyglot, timeout/crash/unavailable and promotion-failure fixtures on both upload paths | Only clean content promoted; no rejected download; private permissions and safe audit/cleanup |
| Cleanup ambiguity | Force a database write to commit but return an error, then force filesystem unlink and audit-write failures for clinical and laboratory PDFs; run the explicit reconciler after the grace window | A referenced PDF is retained, an unreferenced pending PDF is removed, failed reference checks never delete, and pending/failed counts alert operators without file paths or patient data |
| Object access | Owner/assigned versus other patient/unassigned, missing and malformed IDs on appointments, lab reports, care plans, exercises, histories and clinical reports | No foreign content or mutation; missing/out-of-scope public responses indistinguishable |
| Operations | Simulate worker restart, database loss, scanner loss and restore rehearsal | Fail closed without lost captured state; redacted alerts, recovery and rollback demonstrated |
